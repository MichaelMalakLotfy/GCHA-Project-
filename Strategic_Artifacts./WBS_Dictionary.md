# Work Breakdown Structure (WBS) Dictionary - Phase 1

### 1. Task ID: GCHA-TASK-CAI-001
- **Task Name:** Design Database Schema
- **Description of Work:** Design a robust, scalable relational database structure to store all GCHA patient records securely, ensuring full compatibility with the Berlin AI model requirements.
- **Definition of Done (DoD):** 1. ERD is fully documented. 
  2. Schema is reviewed and signed off by the Berlin AI Lead. 
  3. Documentation is committed to the shared Git repository.

### 2. Task ID: GCHA-TASK-BER-005
- **Task Name:** Train Model on Historical Data
- **Description of Work:** Execute the full training pipeline using the cleaned, anonymized dataset to teach the AI model how to accurately predict patient risk levels.
- **Definition of Done (DoD):** 1. Model completes training without critical errors. 
  2. Training logs show progressive loss reduction. 
  3. Model file is version-controlled and uploaded.

### 3. Task ID: GCHA-TASK-BAN-002
- **Task Name:** Code Doctor Login Screen
- **Description of Work:** Develop the secure entry point for clinical users on the mobile application, integrating directly with the Cairo Authentication API.
- **Definition of Done (DoD):** 1. Code passes peer review. 
  2. UI perfectly matches the London PMO design wireframes. 
  3. Successful authentication token is retrieved from the Cairo API during testing.
